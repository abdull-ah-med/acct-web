# Editor logo sources

These original assets identify Git workflows that can use acct. Each editor links to its vendor, and the logos retain their original colors and proportions.

| Editor    | Original asset                                                                                                            | Brand guidance / attribution                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JetBrains | [Official white wordmark SVG](https://raw.githubusercontent.com/JetBrains/logos/master/web/jetbrains/jetbrains-white.svg) | [JetBrains brand guidelines](https://www.jetbrains.com/company/brand/)                                                                                                            |
| Zed       | White wordmark with blue symbol, extracted unchanged from the SVG on the [official brand page](https://zed.dev/brand)     | [Zed brand guidelines](https://zed.dev/brand)                                                                                                                                     |
| Vim       | [Official Vim SVG](https://www.vim.org/images/vimlogo.svg)                                                                | [Vim logos page](https://www.vim.org/logos.php); the SVG retains its original metadata.                                                                                           |
| Neovim    | [Official Neovim mark SVG](https://raw.githubusercontent.com/neovim/neovim.github.io/master/static/logos/neovim-mark.svg) | Neovim logo by Jason Long, licensed [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), used without modification; attribution appears on [neovim.io](https://neovim.io/). |

The logos do not imply vendor endorsement. IDE account sign-ins and provider integrations are separate from acct's Git configuration.
